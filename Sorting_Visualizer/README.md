# Sorting Algorithm Visualizer

A web-based tool to visualize how different sorting algorithms work step by step.

## Live Demo

🔗 [Click here to view the project](https://shaikhdanish-create.github.io/Sorting_Visualizer/)

## Features

- Visualize multiple sorting algorithms
- Adjustable array size and speed
- Color-coded bars for easy tracking
- Play, pause, and reset controls
- Comparison, swap, and timing statistics
- Optional sound feedback
- Interactive and responsive design

## Algorithms Implemented

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to run the project locally

1. Clone the repository:

```bash
git clone https://github.com/shaikhdanish-create/Sorting_Visualizer.git
cd Sorting_Visualizer
```

2. Open `index.html` in your browser.

You can also use a local static server, for example:

```bash
npx serve .
```

Then open the URL shown in the terminal (usually `http://localhost:3000`).
